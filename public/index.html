03 / HEROKU DEPLOYMENT

Pair once.
Persist safely.

Heroku dyno files are temporary. The included worker stores Baileys auth state in PostgreSQL so it can reconnect after a restart.

Get Heroku-ready source ↓
01

Provision a Postgres database

Set DATABASE_URL and run the included schema initialization. Use a durable PostgreSQL service supported by your hosting plan.

02

Configure and deploy the worker

Set owner numbers and optional provider keys as Heroku config vars, then deploy the repository and scale the worker process.

03

Pair from worker logs

Set PAIRING_NUMBER once to request a short-lived code. Enter it in WhatsApp Linked Devices; credentials are saved to Postgres.

!

Pair now opens an external service supplied by the project owner; it is not operated by this site. A WhatsApp pairing code can link your account—never share it publicly. Third-party providers need their own credentials. A one-click Heroku launch requires a public GitHub repository URL; this source package includes setup instructions instead.
